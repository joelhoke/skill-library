Skill Library

Find the workflows you’ve built, keep the useful versions, and give your next project a head start.

Open the app

Build and open Skill Library.app using the instructions in README.md. You can move it to Applications if you prefer. Library data is stored in ~/Library/Application Support/Skill Library. Source builds start with an empty library; subsequent launches preserve your changes.

This is a locally built Apple silicon app for macOS 14 or later, signed for local use. It is not a notarized public release. It runs without an AI API account, server, or network connection.

1. Browse what you already have

Use Add skills to scan your personal skills and project folders or import a complete skill folder. Identical copies share one entry with their source locations; differing versions remain available for comparison.

Search names, descriptions, origins, categories, dependencies, or source paths. Select a card to read its details, edit instructions, browse supporting files, organize it, or compare saved revisions. Changes create a new library revision; source projects stay untouched. Use the Hidden filter to show entries you’ve hidden.

StatusMeaning
ReadyExisting skill passed structural checks, or you reviewed a draft. This does not mean its scripts have been executed or behavior certified.
DraftA recovered or edited workflow needs review before project use.
Needs repairMissing metadata, invalid naming, or a missing local reference. Edit and save a revision, then review it.

2. Recover workflows with Codex

Open Recovered drafts → Recover with Codex. The app copies a recovery prompt and reveals the companion skill folder. Paste the prompt in a Codex task and supply that folder if requested. Codex can review accessible task history, project instructions, or conversation exports and produce an import package.

Use Add skills → Import skill or recovery package and choose the produced folder containing package.json. Review each draft’s sources and dependencies, make any edits, then choose Mark reviewed & ready. The app does not call private history APIs or automatically gain access to other devices.

Recovery coverage is explicit. Imported packages record which sources were inspected, what evidence supports each draft, and which sources were unavailable. Task summaries alone cannot establish a ready skill. See View scan & recovery coverage.

3. Make a starter kit

Open Starter kits → New starter kit. Name it, select reviewed skills, and optionally choose a folder of starter files. That folder’s contents will be copied to the project root. Each kit pins exact skill revisions, so future library edits do not silently change it. Edit the kit and select the update checkbox to adopt newer revisions.

Third-party tools and runtime dependencies remain prerequisites; preparing a folder does not install them.

4. Prepare a project

  1. Choose Prepare project, then a starter kit or individual skills.
  2. Select an existing project folder or choose a location for a new folder.
  3. Choose Preview changes. Every proposed file is listed as Add, Conflict, or Unchanged.
  4. For each conflict, compare contents and explicitly choose Keep existing or Replace with selected.
  5. Apply the changes. Open a fresh Codex task in that project folder to discover its .agents/skills skills.

The app records installed revisions in .skill-library.json. Unchanged files are skipped. Existing extra files stay in place. Templates may propose edits to project instructions, but an existing file always requires conflict resolution.

5. Check changes or roll back

In Projects, choose Check installed skills to see local edits, missing files, and available library updates. To apply an update, prepare the project again using the desired revisions. Older extra files are preserved and appear as local differences.

Roll back restores overwritten files and removes added files only when they still match what this preparation wrote. Files edited afterward are preserved and reported. If the app closes during preparation, its Applying record remains in Projects; roll it back before retrying.

Refresh, export, and back up

Add skills → Scan default folders scans personal skills, Desktop, Documents, and previously added roots. Scan another folder to include more work. Build output, dependencies, system skills, plugin caches, app bundles, and folders containing .skill-library-ignore are excluded. Permission failures appear in coverage. Refresh is manual.

Export complete skill creates a portable folder package with all selected skill files and provenance. Import into another library as a reviewable draft. Back up the whole app-managed library folder, including its catalog, skill revisions, templates, and transactions. Close the app before copying a live library backup. The app holds an exclusive library lock to avoid simultaneous writers.

Small changes you can make yourself

Use the app to edit categories, origins, dependencies, instructions, and starter-kit selections. Those edits take effect in the library immediately; project copies change only when you prepare them again. For example, repair missing skill metadata in the opening frontmatter, save the revision, and mark it reviewed after checking its instructions and supporting files.

For source-level appearance changes, Sources/SkillLibrary/ContentView.swift defines the primary accent (#3B9EC8; RGB 59, 158, 200), 240-point minimum card width, and 26-point outer padding. Increase card width to show fewer, wider columns. AppModel.swift defines the 1320 × 850-point default window. Rebuild the app after source edits; your stored library is separate. Changes to catalog formats, file handling, or rollback deserve implementation help and the test suite.

Source and reproducibility

The repository includes the Swift package, unit tests, recovery skill, package format, guide, and build script. Open Package.swift in Xcode, or run ./build-app.sh. The build uses Apple frameworks only; there are no Swift package downloads. The repository excludes personal library data and recovery packages. Keep backups of those separately on your Mac.
